#Expense Tracker Backend (Java OOP Project)

A Java backend for tracking personal expenses using OOP principles. Supports adding, deleting, filtering, and sorting expenses with data stored in a text file.

#Features
  Add, delete, update expenses
  Categorize by type (e.g., Food, Travel)
  Filter & sort by date/amount
  Uses ArrayList for data storage
  Custom error handling

#Technologies
  Java (JDK 8+)
  OOP principles
  File storage

#Project Structure
  Expense.java – Expense model
  ExpenseOperations.java – interface 
  InformationManagement.java – File I/O
  User.java – Logic to perform CRUD operation
  Main.java – Program entry point which takes input and evaluates using static method

#How to Run
  Clone the repo:
  Command ----> git clone https://github.com/Sahana-36-Aradhya/Expense_Tracker_Using_Java_OOPS.git
  Open in IDE (Eclipse, IntelliJ,VS Code).
  Run Main.java.
